## 🚀 Quick Start

### Option 1: NPM Command (Recommended)
```bash
npm run onboard <client-name>
```

### Option 2: GitHub Actions (Production)
1. Go to **Actions** tab in GitHub
2. Select **"🚀 Onboard New PixelUp Client"** workflow
3. Click **"Run workflow"**
4. Enter client name and optional parameters
5. Click **"Run workflow"**

### Option 3: Direct Script
```bash
node scripts/onboard.js <client-name>
```
